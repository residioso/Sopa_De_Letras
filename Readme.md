## Descripción
Sopa de Letras es una aplicación web desarrollada con HTML, CSS y JavaScript que permite a los usuarios encontrar palabras ocultas dentro de una cuadrícula de letras. El objetivo es localizar todas las palabras incluidas en la lista antes de finalizar la partida.

## Características
- Generación de una cuadrícula de letras.
- Lista de palabras a encontrar.
- Selección de palabras mediante el ratón.
- Resaltado de palabras encontradas.
- Contador de palabras restantes.
- Diseño adaptable a diferentes tamaños de pantalla.

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
